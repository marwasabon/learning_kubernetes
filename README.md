# Shortcode Application


This is a Java 8 application built using Spring Boot that allows users to generate shortcodes for corporates. 


## How to Use


1. Clone the repository to your local machine.
git clone http://172.20.2.102/enterprise-systems-development/zain-shortcode.git

2. Run the application using your preferred IDE or by executing the command ./mvnw spring-boot:run in the project directory.

3. Once the application is running, navigate to localhost:8000 in your web browser.

4. The login page will be displayed on the screen.


## Technologies Used


- Java 8

- Spring Boot
